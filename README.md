# Дом на 6 соседей — текстовый прототип «Опять здесь»

Симуляция одного подъезда пятиэтажки на 30 дней метели. Без графики, без движка,
без игрока — только соседи, их запасы, страх и то, что они друг с другом делают.

Проверяемая гипотеза одна: **рождает ли система из GDD рейды, союзы и предательства
сама по себе — или их придётся расписывать вручную.**

Всё сделано по дизайн-документу: черты 0–10 (жадность, храбрость, лояльность,
общительность, вспыльчивость), четыре шкалы отношения (осведомлённость, паника,
ненависть, страх) плюс доверие 0–10, шум и наблюдение из раздела 13, слово
из раздела 14, осада по стадиям из раздела 16, три типа событий и погода
из раздела 21, нормальность и собрание жильцов из раздела 12.

---

## Как запустить

Нужен Python 3.8+ (проверено на 3.12). Из папки `prototype`:

```bash
python run.py
```

Одна жизнь дома, 30 дней, случайное зерно. Зерно печатается в конце — по нему
прогон повторяется до последнего слова.

```bash
python run.py --зерно 42
```

Полезные ключи:

| Ключ | Что делает |
|---|---|
| `--дней 15` | другая длина метели |
| `--зерно 42` | повторить конкретный прогон |
| `--подробно` | печатать каждое действие каждого жильца (много) |
| `--тихо` | только крупные события |
| `--секреты` | показывать то, чего дом не знает: кто на самом деле украл |
| `--файл лог.txt` | записать в файл, а не в консоль |

Сто жизней подряд со сводной статистикой (около 25 секунд на восьми ядрах):

```bash
python batch.py --прогонов 100
```

Одна история ничего не доказывает — сто историй показывают, что система делает
**обычно**. Рядом с каждым средним стоит «±»: половина 95%-интервала. Если две
настройки разошлись меньше чем на этот размах, они не разошлись вовсе.

Самопроверка — после каждой правки:

```bash
python check.py
```

Проверяет данные, инварианты, баланс ресурсов, покрытие веток, детерминизм
и совпадение с эталонным прогоном. Возвращает код 1, если что-то не так.
Если поведение изменилось намеренно, эталон переписывается осознанно:
`python check.py --золотой`.

Отдельная линейка — то, чем меряется живость дома:

```bash
python замер.py --прогонов 100
```

Доля ранних краж и запас у вора в момент кражи, настроение и нормальность
по дням с размахом между людьми, день первого крайнего поступка у каждого,
враньё и его разоблачение, обещания и их нарушения, собрания, погода
и чем дом занят в буран.

Линейка к последнему заходу — что происходит снаружи и что дом об этом знает:

```bash
python снаружи.py 60
python живость.py 60      # как решают сами жильцы: выбор, пары, взгляд, замысел
```

Снег по дням, травмы и встречи по местам и по неделям, вытяжка и угар, задержка
между смертью и известием о ней, уходы к пункту обогрева и возвраты с полпути.
Ручку можно подменить прямо в вызове, не трогая файл: `python снаружи.py 60
снег_дорога=0.1`.

Сравнить две настройки одной ручки:

```bash
python ab.py агрессивность_дома 1.5 2.0
```

Это и есть главный инструмент настройки, а не `batch.py`. Зёрна парные: зерно 7
при 1.5 сравнивается с зерном 7 при 2.0, один и тот же мир, отличается только
ручка — так уходит половина шума. Рядом с каждой разницей написано, отличается
она от шума или нет. Файл `balance.json` при этом не трогается.

## Как читать вывод

```
══ ДЕНЬ 14 · метель · -21°C · без отопления, без воды, без света, без связи
  ◆ На лестнице между четвёртым и пятым лежит человек из третьего подъезда...
  [чат] Лида: Если кто-то берёт чужое — лучше признайтесь сейчас.
  Игорь разобрал часть кв.6: взял еда 3, топливо 3
  Пётр сам занёс еду Лиде
  Костя попросил еды у Виктора — отказали
  НАЛЁТ. Игорь, Костя — к двери кв.9 (Лида).
  На лестницу вышли: Виктор — за Лиду.
  Лида откупилась: отдала топливо 2. Ушли.
  ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄
  Лида   кв9  сыт 46 вод 66 тепл 41 сон 69 настр 72 здор100 паника 54 │ еда 5.0 ...
```

- `◆` — скриптовое событие (одинаково в каждой жизни), `◇` — случайное внешнее.
- `[чат]` — общий чат жильцов; пропадает к 10-му дню вместе со связью. Реплика
  выходит, только если она сегодня не врёт: «когда включат отопление обратно?» —
  не раньше того дня, когда батареи остыли (`условие` в `lines.json`).
- `нал 14+9` в панели — наличные и (пока живы банки) остаток на карте. После
  второго дня второе число пропадает вместе с деньгами.
- `боится Пётр 74` в панели — четвёртая шкала отношения. Она не про «всё плохо»
  (это паника) и не про «я его ненавижу» (это ненависть), а про «плохо вот
  от него»: человек видел у соседа ружьё в руках или видел, как он кого-то убил.
- «Оксана спустилась в свой погреб» и «Пётр сходил в свой гараж» — это ходка
  в собственную кладовую, и она не вылазка: погреб в подвале этого же дома,
  до него идут час, и его не закрывают ни мороз, ни буран. «в погреб кв.6 —
  тот, что вскрыли» значит, что замок там сорван и ходят туда все, кто знает.
- `дыры: окно+стена` в панели — чем эту квартиру вскрывали. Дыра остаётся
  в стенах: в неё дует, за ней не спрятаться, через неё войдут в следующий раз.
- Пунктирная линия и ниже — **панель скрытых шкал**. Это то самое отладочное окно,
  без которого невозможно понять, почему сосед пришёл с дубиной. Игрок этого
  никогда не увидит: у него будет только сводка дня и красные края экрана.

В конце — итог: кто выжил, кто когда погиб, хроника дома, счётчики, группы,
матрица отношений «доверие/ненависть/осведомлённость», список «кого в доме
боятся», список проломов по квартирам, состояние кладовых (заперта или вскрыта,
сколько ходок, что осталось, у кого ключ) и диагностика для настройки.

## Где крутить цифры

Всё, что настраивается, лежит в `data/`. «Код вообще ничего не хардкодит» было бы
неправдой — числовых литералов в `house/*.py` больше тысячи, — но ни одно число,
которое имеет смысл крутить, в коде не сидит: `python check.py` отдельно проверяет,
что в `balance.json` нет мёртвых ручек и что код не читает ключей, которых там нет.

| Файл | Что там |
|---|---|
| `data/balance.json` | все числа: расход еды, градусы, пороги налёта, шум, лимиты |
| `data/npcs.json` | шесть жильцов: черты, запасы, оружие, убежище, стартовые отношения; пустые квартиры; кладовые (погреба и гаражи) |
| `data/events.json` | скриптовые события по дням и случайные внешние |
| `data/lines.json` | реплики чата и обычной жизни; у реплики бывает условие (`отключено`, `работает`, `до_дня`) — тем же языком, что у событий |

Правится блокнотом, программировать не нужно. Несколько ручек, которые
меняют игру сильнее всего:

- `расход_сытости` и `еда_за_порцию` — насколько быстро дом проедает запасы;
- `вылазка_добыча_база` и `вылазка_истощение_за_ход` — щедрость района и скорость,
  с которой он выгрызается досуха;
- **кладовые (погреба и гаражи).** Что в них лежит — в `npcs.json`, раздел
  `кладовые`; наполнять их надо, вынимая то же самое из стартовых запасов
  квартир, иначе дом просто становится богаче. В `balance.json`:
  `кладовая_за_раз` (сколько уносят за ходку), `кладовая_поднимает_дней`
  (на сколько дней вперёд поднимают наверх — это оно решает, за сколько дней
  погреб опустеет), `кладовая_заметность` (насколько дом видит, кто ходит
  в подвал), `гараж_попал_на_соседский` (шанс, что сорванный в общем ряду
  замок оказался соседским), `кладовая_вскрытие_решимость` и
  `кладовая_вскрытие_за_нужду` — насколько трудно решиться на чужой замок;
- **снег.** `снег_за_день` и `снег_уплотнение` задают всю кривую: первое —
  сколько досыпает, второе — какая доля лежащего слёживается за день. Их
  отношение и есть высота, к которой снег придёт (`снег_потолок` — жёсткий
  предел сверху). Дальше он входит ровно в три места: `снег_дорога` (во сколько
  раз дольше идти), `снег_травма` (насколько легче сломать ногу) и
  `пункт_за_снег` (насколько труднее дойти до школы №7). Крутить `снег_дорога`
  надо, глядя не на число вылазок, а на часы, проведённые на улице: ходок
  становится меньше просто потому, что каждая длиннее;
- **вытяжка и угар.** `вентиляция_замерзает` — главная ручка, она решает,
  в скольких жизнях вообще кто-то угорит. `вентиляция_за_утепление` — сила
  ловушки (чем плотнее заклеены окна, тем быстрее мёрзнет шахта),
  `вентиляция_признак` и `вентиляция_смерть` — два порога, между которыми
  у человека есть время догадаться, а `вытяжка_вес` и
  `вытяжка_сообразительность` — насколько он вообще способен догадаться сам;
- **уход.** `пункт_база` — шанс не повернуть с полпути (остальные `пункт_*`
  вычитают из неё снег, мороз, раны и ребёнка), `уйти_решимость` — насколько
  трудно вообще решиться, `уйти_унесёт` — сколько уносят с собой. Последнее
  и держит дом от опустошения: чем больше можно унести, тем выгоднее уйти;
- `смерть_порог_веры` — с какого доверия к рассказчику известие о смерти
  принимают, а не переспрашивают «откуда ты знаешь». `не_открыл_дней`
  и `запах_дней` — через сколько дней молчания к соседу идут посмотреть
  и через сколько тихая смерть перестаёт быть тихой сама собой;
- `своя_мерка` и `своя_мерка_склонность` — как ценности человека держат его
  руку. Первое вычитается (запрет обязан уметь остановить), второе умножает
  (склонность делает охотнее в том, что человек и так собрался делать,
  но не выдумывает ему дела на пустом месте);
- **деньги (GDD 18).** Единица — тысяча рублей, и денег две. Наличные лежат
  в `запасы.деньги` (`npcs.json`) вместе с тушёнкой: их крадут, выносят при
  осаде, они остаются в квартире умершего. `счёт` — карта: её нельзя ни украсть,
  ни спасти. Три группы ручек:
  - `день_отключения_банков` (2) — с этого дня карта мертва, и всё, что на ней,
    просто исчезает. У жильца ровно один день на то, чтобы успеть: закупиться
    картой в магазине или отстоять очередь к банкомату (`банкомат_лимит` —
    сколько дают в руки, `банкомат_касса` — сколько всего в районе на день:
    на всех не хватает);
  - `день_закрытия_магазинов` (3) — пока магазин открыт, вылазка туда это
    покупка, а не обшаривание. `магазин_цена` по позициям,
    `магазин_наценка_в_день` (дорожает с каждым днём), `магазин_унос_макс`
    (сколько человек унесёт), `магазин_кошелёк_норма` (с каким кошельком туда
    вообще стоит идти — без денег в работающем магазине делать нечего),
    `магазин_цена_тулупа` — та самая вещь, которая держит улицу открытой
    до третьей недели;
  - `деньги_цена`, `день_нуля_денег`, `деньги_вера_нормальность` — сколько
    стоит тысяча. Курс дома падает от закрытия магазина к нулю, а поверх курса
    каждый решает сам, берёт ли он ещё бумагу, и решает это его нормальность.
    Отсюда главное следствие: последними деньги принимают те, у кого жизнь
    ещё не рассыпалась;
- `буржуйка_градусов`, `утепление_градус_за_уровень`, `температура_падение_в_день` —
  вся тепловая экономика; сейчас без буржуйки после 12-го дня не выжить;
- `остывание_дома_дней` — за сколько суток панельный дом отдаёт накопленное тепло
  после того, как батареи остыли. День, когда отключили отопление, и день, когда
  в квартире стало холодно, — разные дни. При `1` это одно и то же (так было
  раньше: минус пятнадцать градусов за одну ночь второго дня, и дом уходил
  в выживание с третьего). Четыре значения по 120 прогонов дали 1.29–1.48 при
  ±0.15 — то есть разницы в выживаемости не видно за шумом. Эта ручка решает
  не сколько человек доживёт, а похожа ли первая неделя на первую неделю;
- `налёт_порог_паники`, `налёт_порог_ненависти`, `налёт_порог_осведомлённости` —
  условие запуска осады прямо по разделу 16 GDD;
- `доверие_порог_союза` — насколько трудно людям сговориться;
- **ребёнок, прощение и площадка** (шестой заход):
  - `ребёнок_вес_беды` — с каким весом беда ребёнка входит в «мне сейчас плохо»
    у матери. Через неё же он попадает в панику, в просьбу и в переезд;
  - `вина_оставляет_дней` и `вина_вес_поступка` — сколько виноватый оставляет
    себе, идя мириться, и насколько охотно он на это идёт. Первое и есть
    единственный тормоз: излишка ему не нужно, он несёт из своего;
  - `собрание_ссора` и `собрание_вес_напряжения` — насколько легко площадка
    срывается в крик и насколько зовущий это предвидит. Обе считаются одной
    формулой `meeting.жар_ссоры`, поэтому крутить их надо парой: первая — цена
    ошибки, вторая — способность её увидеть;
  - `горе_за_близость`, `горе_за_доверие`, `горе_порог_своего`, `горе_пол` —
    насколько смерть своего тяжелее смерти соседа и с какого порога она
    опускает сам пол нормальности;
  - `быт_отступает` — насколько обычная жизнь уступает беде. При нуле человек
    переставляет банки в шкафу, пока на руках горит ребёнок; при двойке быт
    исчезает совсем, и вместо него человек ложится;
  - `взгляд_стареет` — на сколько в день выцветает впечатление о соседе.
    Решает, с какой уверенностью человек судит по лицу, которое видел неделю назад;
  - `шепнуть_против_ума` — насколько умный избегает прямого наговора. Это
    и есть вся разница между двумя способами интриги: не что они делают,
    а чем предпочитают пользоваться;
- `снег_топливо`, `снег_вода`, `снег_на_горящей_печке` — цена воды в топливе.
  Снег топят только там, где есть буржуйка или живой обогреватель, и при этом
  **греется комната**: топливо не пропадает. Если печка уже топится, снег стоит
  доплаты; если холодная — платишь как за топку, но получаешь и тепло;
- `горизонт_старт`, `горизонт_за_день`, `горизонт_за_панику`, `горизонт_за_жадность` —
  на сколько дней вперёд человек считает нужным иметь запас. Никто не знает,
  когда кончится метель, поэтому срок растёт с каждым днём — отсюда жадность.
  Это самая сильная ручка социального поведения: подними `горизонт_за_день`,
  и дом перестанет делиться вообще;
- `запах_база`, `запах_вверх`, `запах_вниз`, `запах_осведомлённость`, `запах_зависть` —
  запах готовки. Отдельный канал от звука: вверх по стояку доходит лучше, чем вниз,
  звукоизоляция не помогает, спящий учует. Голодный сосед, учуяв чужой ужин,
  получает настоящую прибавку к ненависти;
- `тело_порций`, `тело_порча_дней`, `людоедство_*` — то, до чего доходят на третьей
  неделе голода. Заложено четыре правила: речь только об уже умерших, ребёнок
  исключён всегда, в журнале это сказано намёком (прямо — только с `--секреты`),
  и это не источник еды, а точка невозврата. Противовес — действие «вынести тело»,
  доступное лояльным: пока в доме жив кто-то вроде Лиды, соблазна просто нет;
- `агрессивность_дома` — **ручка жестокости.** Совесть, лёгкость вербовки,
  готовность откупиться, осторожность вора, решимость отнять на лестнице.
  Пороги запуска осады она больше не трогает: пока она делила их на себя,
  «паника выше половины» из GDD 16 работала как «выше четверти», и записанное
  в документе условие переставало описывать игру. Замерено на 120 прогонах
  каждое значение, «±» — половина 95%-интервала:

  | значение | выжило из 6 | холод | насилие | первая осада |
  |---|---|---|---|---|
  | 1.0 | 1.45 ± 0.13 | 32% | 25% | день 16.4 |
  | 1.5 | 1.43 ± 0.17 | 37% | 27% | день 14.1 |
  | **2.0** (сейчас) | 1.30 ± 0.15 | 34% | 30% | день 13.4 |
  | 2.6 | 1.19 ± 0.14 | 32% | 28% | день 12.9 |

  Читать это надо так: **на темп она влияет слабо** — три с половиной дня
  на всём размахе, и это меньше, чем разброс между жильцами. Решает она,
  чем осада кончится и в какой доле смертей виноваты соседи, а не метель;
  темпом управляют пороги GDD 16 и нормальность. И доля насилия упирается
  в потолок: к 2.6 она даже падает, а выживаемость роняет ещё на 0.11, —
  потому что к концу метели пороги налёта и так пройдены, а ночей в календаре
  конечное число;
- `отъём_*` — отнять на лестнице. Без двери и замка: сильный ловит слабого,
  чаще всего того, кто вернулся с улицы с пакетами. Берут только то, что в руках
  (`отъём_максимум`), сопротивление кончается потасовкой, а не боем. Это то, что
  делает дом опасным каждый день, а не раз в неделю;
- `нормальность_*` — **главная ручка темпа.** Пока батареи ещё тёплые и в чате
  обсуждают, когда починят котельную, разобрать чужую квартиру или заколотить
  дверь просто не приходит в голову. Это состояние, а не формула: падает в момент
  события (отключение, происшествие, смерть, чужой крайний поступок, свой первый),
  чуть отрастает за три тихих дня и упирается в личный пол из `npcs.json` —
  `нормальность_пол` и `нормальность_скорость`. Их и надо крутить, если нужно
  развести людей по срокам: у Лиды пол 0.40, у Игоря 0.04, и между их первыми
  крайними поступками проходит девять дней. Чужой пример весит столько, сколько
  весит сам поступок (`НОРМА` в `actions.py`), и работает через доверие:
  заколоченная дверь уважаемого соседа — разрешение для всех, та же дверь того,
  кого не любят, — повод его бояться;
- `собрание_*`, `дежурство_*`, `дверь_подъезда_*` — площадка. `собрание_доверие`
  решает, кому дом вообще даст себя собрать, `собрание_решимость` — как часто
  зовут, `собрание_ссора` — как часто это кончается криком (сейчас 39%);
- `ложь_*`, `наговор_*`, `обещание_*` — слово. `ложь_за_нормальность` держит
  враньё в узде, пока жизнь ещё обычная; `ложь_шанс_раскрыть` и `ложь_вес_слов`
  задают его цену; `обещание_вес_репутации` — насколько тяжело потом
  договариваться тому, кто слова не сдержал;
- `буран_*` и `затишье_*` — режимы погоды. Буран запирает дом и глушит все
  сигналы (`буран_шум`), затишье открывает улицу и слух;
- `ребёнок_*` — своя шкала Вани: как быстро он мёрзнет, сколько ему достаётся
  еды, как далеко мать может уйти с ним на руках (`ребёнок_предел_часов`);
- `страх_*` — **четвёртая шкала отношения.** Растёт от увиденного: оружие
  в руках (`страх_за_оружие` на вес оружия, `страх_за_огнестрел` сверху),
  убийство (`страх_за_убийство` плюс `страх_убийство_оружие` — смотря чем убили),
  разбой на лестнице и налёт на твою дверь. Ружьё, которое ни разу не сняли
  со стены, никого не пугает: `страх_видно_оружие` — шанс разглядеть его при
  наблюдении. Забывается медленнее злости (`страх_спад_в_день` 0.35 против 0.5
  у ненависти). Дальше — двенадцать весов, и все они про одно: страх не толкает,
  а держит. `страх_вес_контакта` (не идут говорить, просить, меняться,
  присматриваться), `страх_вес_двери` (не открывают), `страх_уступает`
  (а открыв — отдают, чтобы ушёл), `страх_вес_кражи`, `страх_вес_отъёма`,
  `страх_вес_насилия` (не берутся за нож), `страх_вес_налёта`,
  `страх_вес_вербовки`, `страх_вес_защиты` (не выходят за соседа на лестницу),
  `страх_вес_побега`, `страх_вес_откупа`, `страх_вес_соседства`;
- `налёт_упорство_*`, `пролом_*`, `окно_*`, `дыра_*` — стадия «другой путь»
  в осаде. `налёт_упорство_за_нужду` — главная из них: уйдёт ли группа
  от целой двери, решает не злость, а нужда. `окно_мороз` и `окно_доступ` —
  когда и с какой стороны можно влезть в окно, `окно_за_утепление` — насколько
  заколоченные окна этому мешают, `стены_нужно_людей` — объединённый рейд
  из GDD 16, `налёт_упорство_отчаяние` — с какого отчаяния на стену лезут
  и в одиночку. `дыра_градусов` — во сколько градусов обходится пролом
  (окно 6, стена 3.5, перекрытие 3), `дыра_защита` и `дыра_кража` — насколько
  после этого квартира перестаёт быть квартирой, `дыра_чинят` — насколько
  охотно её латают;
- `костёр_порог_комнаты`, `костёр_за_градус`, `костёр_за_тело`,
  `костёр_решимость` — костёр посреди комнаты. Отвечает на холод **в комнате**,
  а не на озноб в теле: промёрзшее тело отходит само, за ночь у тёплой стены.
  Пока считалось наоборот, огонь разводил тот, кто вернулся с семичасовой ходки,
  — в квартиру, где двадцать градусов;
- `разбор_вес_улицы`, `разбор_взлом_решимость`, `ненависть_за_разбор` — разбор
  чужой пустой квартиры. Первая ручка — та же, что у кражи: пока улица кормит,
  доски несут с улицы. Вторая — цена сорванного замка: запертая квартира и
  распахнутая после похорон это разные квартиры. Третья — то, что у пустой
  квартиры может быть живой хозяин, который греется у соседа;
- `переезд_страх_дров`, `переезд_страх_еды`, `переезд_гость_топит`,
  `переезд_согласие`, `теснота_отказ`, `переезд_максимум_гостей` — то, как
  хозяин решает, пустить ли. Считает он не «хватит ли мне до конца метели»,
  а «стану ли я от него беднее»: гость приносит свои дрова, а печка горит одна
  на комнату;
- `порог_действия` — ниже какой оценки человек просто не берётся за дело.
  Без него у него 16 часов, которые надо чем-то занять, и он от нечего делать
  идёт разбирать чужую квартиру;
- `переезд_*` и `теснота_*` — съехаться в одну квартиру. Одна печка на двоих
  греет обоих, и это единственный способ пережить последнюю неделю. Цена —
  нервы, чужой кашель и то, что своя квартира остаётся пустой;
- `мебель_за_топку` — сколько материалов уходит в печку, когда топливо кончилось.
  Настоящий выбор: утеплиться или дожить;
- `паника_дно_*` — у тревоги есть дно, и оно поднимается само. Двадцатый день
  метели без света и новостей пугает независимо от того, что у тебя в шкафу;
- `просьба_*` — память о просьбах. Человек помнит, кто ему дал, а кто отказал:
  к щедрому идёт первым, после двух отказов подряд не подходит неделю, у того,
  кому сам недавно помог, не просит вовсе. Это же обсуждают в разговорах, поэтому
  у каждого складывается репутация щедрости — она печатается в финальном отчёте.
  `просьба_вес_памяти` решает, насколько сильно память правит выбор;
- `отказ_осведомлённость` — отказавший выдаёт себя: «жмётся — значит есть».
  Отказ работает почти как наблюдение и делает скупого мишенью;
- `лимит_в_день` и `лимит_на_пару_в_день` — сколько раз за день можно повторить
  одно и то же. Без этих ограничений один Игорь за сутки двадцать раз просит
  еды у одной Лиды (так и было на первом прогоне).

## Три акта

Так это выглядит по дням (100 прогонов, медиана дня, когда это случилось впервые):

| День | Что происходит |
|---|---|
| 1 | обычная жизнь: радио, чат, разговоры; магазин ещё работает — кто с наличными, тот закупается, кто с картой, тот успевает потратить её или бежит к банкомату; у кого есть погреб, тот спускается в подвал; первый обмен с соседом; к вечеру клеят окна |
| 2 | батареи стали холодными — но в квартирах ещё пятнадцать градусов; банк и приложение умерли, и всё, что осталось на картах, исчезло; первая буржуйка — из купленных досок |
| 3 | магазин работает последний день; первый заказ печи у соседа с руками (в 66% прогонов) |
| 4 | магазин не открылся; первая просьба у соседской двери |
| 4–5 | первый костёр посреди комнаты — у того, кому топить нечем, и только когда своя комната остыла (в 77% прогонов); первая вылазка не в магазин и не в свою кладовую — двор, мусорки, а следом подъезд напротив и гаражный ряд за домом |
| 6 | первый отъём на лестнице; первый разбор пустой квартиры на доски — с сорванным замком; первый сорванный замок в подвале; первая укреплённая дверь: дом начал бояться сам себя |
| ~8 | последняя сделка за деньги; первый переезд к соседу (в 65% прогонов); первая подбитая куртка |
| 10 | первая попытка ночной кражи; свет погас — и если движок пережил метель, у кого-то заводится генератор |
| 11 | первая удавшаяся кража; первое наблюдение за соседом |
| 14 | первая осада; первая смерть; первое собрание на площадке (в 70% прогонов); первое тело вынесли во двор; первая занятая пустая квартира (в 41% прогонов) |
| ~15 | первая дневная кража — когда хозяин на вылазке |
| ~21 | первый пролом: в квартиру вошли не через дверь (в 22% прогонов) |
| ~25 | до тела доходят (в 80% прогонов) |

Первая неделя мирная не потому, что так подкручены числа,
а потому что до чужой двери никто не доходит: сначала должна упасть нормальность,
потом подняться паника выше половины — как и написано в GDD 16. И потому, что
пока на улице есть что взять, чужая дверь проигрывает вылазке: в оценку кражи
входит то, сколько, по мнению этого человека, ещё осталось в районе.

Разные люди приходят к одному и тому же в разные дни, и это главное, что должно
быть видно в таблице: между первым крайним поступком Игоря (день 4) и Лиды
(день 11) проходит семь дней. Ломается это через `нормальность_пол`
и `нормальность_скорость` в `npcs.json`, `кража_вес_улицы` и `порог_действия`.

Два поступка в этой таблице уехали позже нарочно, и это была отдельная правка.
Костёр посреди комнаты жгли на второй день метели — в квартирах, где было плюс
двадцать: оценка смотрела на озноб в теле, а не на холод в комнате, и его
разводил тот, кто промёрз на семичасовой ходке. Чужие пустые квартиры начинали
разбирать на третий день, при работающем ещё магазине: у разбора не было
ни конкуренции с улицей, ни цены за сорванный замок. Обе медианы сдвинулись
на пять и на восемь дней, и первая неделя перестала выглядеть третьей.

## Осада: чем ещё войти

Дверь выдержала — раньше на этом всё и кончалось. Один бросок «инструменты против
засова», и группа расходилась под утро; четверть всех осад упиралась ровно в него,
а обороняющемуся не нужно было ничего, кроме второго уровня двери.

Теперь у осады есть стадия «другой путь» — ровно по разделу 16 GDD, где стены
и потолок названы отдельной стадией:

| Путь | Когда доступен | Что защищает |
|---|---|---|
| **окно** | не буран и теплее −30°; со двора на первом этаже, с крыши на пятом, по балконам между | заколоченные окна (`утепление`), люди на площадке |
| **стена** | на площадке есть пустая или своя квартира | арматура (убежище 4 уровня) |
| **потолок** | такая же квартира этажом выше | то же |
| **пол** | такая же квартира этажом ниже | то же |

Что доступно, решает не бросок кубика, а геометрия подъезда: над Лидой на третьем
стоят кв.14 и кв.16, рядом с Петром на пятом — пустая кв.20, а к Игорю на первом
снизу не придёт никто, там подвал.

Пойдут вокруг или уйдут — решает **упорство**, и это не злость, а нужда
(`налёт_упорство_за_нужду`): человеку, у которого дома пусто, некуда идти от этой
двери, дома его ждёт то же самое, только без еды. Стену и перекрытие ломают
втроём — «объединённый рейд» из GDD 16 — или в одиночку, если терять уже нечего
(`налёт_упорство_отчаяние`).

И у победы появилась цена, которой не было. **Пролом остаётся в стенах** так же,
как утепление: выбитое окно уносит шесть градусов, пролом в стене — три с половиной,
за ними больше не спрятаться (`дыра_защита`) и в следующий раз через них войдут
уже без всякой осады (`дыра_кража`). Перекрытие ломают из другой квартиры — и дыра
появляется сразу в двух, в том числе в собственной, если работали из своей.
Заделывается всё это действием «утепление»: те же материалы, та же работа,
и сначала латают дыру, а потом клеят окна.

Отсюда сама собой выходит иерархия способов: за квартирой лезут через стену,
а не в окно, — потому что выбитая рама в метель дороже вынесенного шкафа.

На 100 прогонах пролом случается в 22% жизней, медиана — 21-й день: стена 8,
окно 7, потолок 6, пол 2. Это не главный путь в квартиру и не должен им быть;
он важен тем, что «дверь выдержала» перестало быть концом разговора. Исход
«отбился» упал с 36% до 18%, а «арматура по стене» — постройка четвёртого
уровня, которую до сих пор не выбирал никто, — впервые кому-то понадобилась.

## Страх перед соседом

Четвёртая шкала отношения рядом с осведомлённостью, паникой и ненавистью
(GDD 12.3). К ненависти она не сводится: бояться можно того, на кого не злишься
вовсе.

**Растёт от увиденного.** Оружие в руках — в дверях, на площадке, на лестнице,
в чужой прихожей во время наблюдения; вес берётся из самого оружия, у огнестрела
отдельная надбавка. И убийство — причём смотря чем убили: выстрел на лестнице
и драка на кулаках оставляют после себя разный дом. Ружьё, которое ни разу
не сняли со стены, никого не пугает: страх берётся из увиденного, а не из чужого
инвентаря. Смелому страшно меньше — храбрость делит, но не отменяет.

**Держит, а не толкает.** К тому, кого боятся, не идут ни говорить, ни просить,
ни меняться, ни присматриваться; ему не открывают дверь — а открыв, отдают банку,
чтобы ушёл; к нему не лезут ночью и его не зажимают на лестнице; за него
не выходят на площадку, когда за ним пришли; с ним не съезжаются, от него
съезжают, и от его двери уходит даже собравшаяся группа.

Это и есть «угроза оружием часто ценнее выстрела» из GDD 17 — только растянутая
на все дни после. До сих пор ствол в дверях работал ровно один раз, в ту самую
минуту, и наутро о нём не помнил никто.

Кого в доме боятся (100 прогонов, случаев, когда страх перевалил за 40):
Пётр 219, Виктор 92, Игорь 66, Оксана 13, Костя 10, Лида 0. Это не подкручено:
у Петра винтовка, у Виктора топор, у Лиды нет ничего, и она единственная,
кого в этом доме не боится никто.

И обратная сторона, которой не было в замысле: **страх сбивает людей в кучу.**
Тот, кто боится соседа с топором, ищет, к кому прибиться, — паника отвечает
за «всё плохо», а страх за «плохо вот от него», и к чужой печке гонит второе.

## Съехаться: пары, тройки и котёл

GDD 15 говорит, что без переезда дом до конца метели не доживает. Прототип
до этой правки не доживал по другой причине: **хозяин отказывал в 96 случаях
из ста.** Он мерил просьбу против собственного горизонта, а тот к третьей неделе
просит двадцать шесть дней запаса, которых нет ни у кого, — и оба вычета
(«лишний рот», «лишние дрова») срабатывали всегда. За сорок жизней случалось
восемь переездов на двести просьб.

Ту же ловушку до этого нашли в щедрости, и её стоит записать как правило:
**решение, упирающееся в горизонт, подменяется арифметикой и не принимается
никогда.** Считать надо не «хватит ли мне до конца метели», а «стану ли я от него
беднее». Гость приходит со своими дровами, и в тот же вечер они уходят в общую
печку, а печка горит одна на комнату — сколько бы человек в ней ни сидело;
с едой иначе, это лишний рот, и он считается полностью.

После правки: переездов 73 на 100 жизней, сожительство складывается в 68% жизней.
Сколько человек под одной крышей (максимум за жизнь, 100 прогонов):

| Под одной крышей | Жизней |
|---|---|
| один (никто не съехался) | 32 |
| двое | 60 |
| трое | 6 |
| четверо | 2 |

Пара — норма, тройка — редкость, и не потому, что запрещено (`переезд_максимум_гостей`
это позволяет): пока в подъезде есть свободные хозяева, шестеро разбиваются на пары,
и третьему в занятой квартире нет прибавки, кроме тесноты. Тройки случаются, когда
свободных уже не осталось, — то есть после смертей. Вчетвером сходятся только через
собрание: это общий котёл из GDD 15, и он остаётся единственным способом собрать
полдома в одну квартиру.

С группами для налёта картина другая и лучше: состав 1 — 54 осады, 2 — 149,
3 — 47, 4 — 13. «Объединённый рейд» из GDD 16 (трое и больше) — это 23% всех осад,
и именно он открывает стадию стен и перекрытий.

## Деньги: три дня и неделя

Своя дуга, и она короче всех прочих. Единица — тысяча рублей; денег две, и вся
разница между ними в том, что наличные можно украсть, а цифровые — отключить.
Дом начинает с 42 тысяч наличными и 57 на картах. 80 прогонов:

| День | Что с деньгами |
|---|---|
| 1 | магазин работает, карту ещё принимают. Три закупки на шестерых и два похода к банкомату за прогон. Кто-то берёт тулуп — семь тысяч против семи банок, и это решение на три недели вперёд |
| 2 | банк и приложение мертвы. Всё, что осталось на карте, исчезает: в среднем 14 тысяч из 57 — ровно та четверть, которую не успели снять или потратить |
| 3 | последний день магазина; платят уже только наличными |
| 4 | магазин не открылся. Бумагу ещё берут соседи |
| ~7 | последняя сделка за деньги. Дальше бумага и есть бумага |

За прогон: 5.0 закупок в магазине, 2.3 похода к банкомату, 9.3 сделки за наличные
между соседями (дни 1–9, последняя обычно на седьмой). В доме к концу остаётся
около 23 тысяч, на которые уже ничего не купить, и они честно лежат в панели
рядом с едой и дровами.

Держат эту дугу три вещи. Курс дома (`деньги_цена`, `день_нуля_денег`) — то,
что деньги дешевеют. Личная вера (`деньги_вера_нормальность`) — то, что цена
тысячи привязана к нормальности хозяина, и потому последними деньги принимают
те, у кого жизнь ещё не рассыпалась. И обычная нехватка: продают только те,
у кого запас выше собственного горизонта, а таких к восьмому дню уже нет —
поэтому деньги умирают раньше, чем обнуляется курс, и это правильный ответ
модели, а не её сбой.

## Оружие ходит по рукам

Оружие было единственной вещью в модели, которая исчезала вместе с человеком:
тулуп с мёртвого снимали, а винтовку нет. За двадцать жизней распределение
оружия на тридцатый день ни разу не отличалось от первого — то есть расклад сил
в доме был заморожен на первом дне метели, а вместе с ним и страх, потому что
страх растёт от увиденного оружия.

Теперь оружие лежит либо в руках, либо в стенах. Пять путей, и все пять
описаны в GDD:

| Откуда | Как часто (60 жизней) |
|---|---|
| из чужих стен: кто занял квартиру или разобрал её, тот и вооружился | ~100 |
| вынесли при осаде или ночной краже | 42 |
| отняли у побеждённого — на лестнице или после драки | 17 |
| нашли на улице (нож в гараже, обрез в заброшке; винтовки там не бывает) | 23 |

Слот один: «взял топор» всегда значит «нож положил», и положить его некуда,
кроме стен. Поэтому оружие в доме не размножается — этому есть отдельный
инвариант в `check.py`, такой же, как у банок: было + найдено == осталось.

Меняет это в первую очередь тех, у кого не было ничего. За 60 жизней чаще
всех вооружалась Лида — 52 раза; Пётр, у которого винтовка, — 6. И патроны
перестали быть мёртвым грузом: их цену теперь определяет не дефицит, а наличие
ружья, и их можно выменять тому, кому есть чем стрелять.

## Зов, отказ и дежурный

Вербовка в налёт была молчаливым фильтром: вожак перебирал соседей, кто-то
не шёл, и не происходило ничего. Хуже того — не шёл почти никто: `НОРМА["налёт"]`
применялась к тому, кто зовёт, и не применялась ни к кому из идущих следом,
так что человек с ещё не рухнувшей жизнью соглашался ломать чужую дверь просто
потому, что позвали.

Теперь у зова три следствия. **Позвали — значит рассказали:** осведомлённость
о жертве и паника растут, а привычное рушится, потому что тебе только что
предложили преступление. **Отказ помнят обе стороны:** вожак теряет доверие
к отказавшему и несколько дней не зовёт его снова. **И отказавший может пойти
предупредить** — по лояльности, по тому, насколько жизнь ещё нормальна, и вопреки
страху перед вожаком. Ненависть к жертве мешает, но не решает: к третьей неделе
в этом доме ненавидят все и всех, и если считать по ней, предупреждать некому.

Рядом стоит дежурство. Оно читалось ровно в двух местах — шанс кражи и шанс
убийства соседа, — и 96 осад из 115 приходились на ночи, когда кто-то в доме
не спал, без всякой разницы. Теперь дежурный слышит их на лестнице и поднимает
подъезд; вожак это считает, выбирая ночь.

| | доля осад | обошлось без прорыва |
|---|---|---|
| все осады | — | 55% |
| жертву предупредили | 20% | 70% |
| дежурный поднял дом | 25% | 71% |

## Услуги: умение как заработок

Заказать можно было одну только печь. Всё остальное, что требует рук, мастер
строил себе: пятеро из шести не получали ни генератора, ни стальных листов,
ни арматуры никогда и ни за какую цену — а арматура единственное, что защищает
от пролома в стене.

Теперь заказывают любую работу, которой сам не умеешь: буржуйку, генератор,
листы, звукоизоляцию, арматуру. Доски заказчик отдаёт вперёд и они лежат в углу
у мастера — пока материал ждали до срока, заказы срывались не по злому умыслу,
а потому что доски за эти дни уходили в печку. Оплата едой и дровами по факту,
срок — от умения, у мастера одни руки и очередь на одного. Цена растёт от беды
покупателя, а не от дефицита ресурса: у кого вчера ломали дверь, тот платит
за листы вдвое. Это единственное место в модели, где так.

Медик тоже перестала быть чистым раздатчиком. Плату она просит не по жадности —
она самый лояльный человек в доме, — а по собственному пустому шкафу и по тому,
насколько жизнь уже не та. Отказать в лечении она всё равно не может: она уже
пришла и уже открыла аптечку. Но помнит, кто не заплатил.

Замер на 60 жизнях: 2.3 работы на заказ за жизнь (генератор 48, буржуйка 46,
листы 35, арматура 5, звукоизоляция 2), 68 лечений за плату против трёх в долг.
И постройки третьего-четвёртого уровня появились у пятерых жильцов из шести,
а не у одного.

## Теснота

ГДД называет ценой соседства «тесноту (нервы, чужой кашель, общую болезнь)»
и «накопленную злость», из которой растут разъезд, изгнание гостя и нож ночью.
Разбор показал, что в модели этого не было вовсе: за все дни вместе соседство
давало только минус к доверию, а вся ненависть между сожителями приходила
со стороны — суд над третьими, нарушенные обещания, отказы, подозрения.

Поводы у тесноты нарочно бытовые: печка (топит хозяин, а мёрзнут оба, и злится
тот, кто не решает), чужой шкаф на виду, кашель всю ночь, ребёнок, который
просыпается. Каждый из них мелкий и каждый — каждые сутки. Сейчас на само
соседство приходится 28% всей злости между сожителями, разъездов и выселений
стало вдвое больше, и убийство соседа по квартире перестало быть нулём.

Помощь при этом перестала быть только едой. Замерзающему соседу по своей воле
не приносили дров ни разу: он должен был прийти и попросить, а просьба стоит
и доверия, и гордости, — при том что холод даёт треть всех смертей. Теперь
смотрят, чего соседу не хватает: еда 37%, вода 23%, дрова 21%, аптечка 19%.
И долг помнит, чем брали: взял дрова — вернёшь дрова, а не банку.

## Своё и чужое: погреб, гараж и ключ

Первый день метели, батареи ещё тёплые, магазин на Заречной ещё открыт — и
44% всех вылазок дома уходит в чужие подъезды и гаражи. На второй день 77%,
на третий 83%. Замер, 40 жизней.

Разбор показал, что дело не в характере жильцов. **В модели не было своего
имущества за порогом квартиры.** Всё, что не в шкафу, было ничьим в равной
мере: и мусорка во дворе, и чужой гараж, и чужая площадка. Поэтому «сходить
за своим» и «залезть в чужое» были одним действием с разной добычей, и порядок
между ними задавала арифметика часов: у вылазки стояли одни ворота по времени
на все места (6 часов), а дорога до магазина не бывает короче 8.4 — и человек
решал «выйду за продуктами», а выходил в гаражи, потому что до магазина уже
не успевал. 72% диких вылазок первого дня были этой подменой.

Отдельно нашлось, что **у женщины с ребёнком не было ни одного законного
места.** Предел «с ребёнком далеко не уходят» (1.2 часа) закрывает и магазин,
и гаражи навсегда, а двор заперт дичью, пока жизнь ещё похожа на обычную.
Оставались ровно чужие подъезды, и Оксана шла туда в первый же день каждой
жизни: 103 случая из 229 за первые три дня.

Теперь у части квартир есть кладовая — погреб в подвале или гараж в ряду
за домом. Это **не новый источник еды, а перераспределение**: столько же
банок в мире, но не у всех, не в шкафу и за отдельным замком.

| | |
|---|---|
| погреб кв.6 | закрутки, вода, аптечка — у Оксаны, и это единственное место, куда можно сходить с ребёнком на руках |
| погреб кв.14 | железо, доски, дрова и **движок** — у Виктора, слесаря и электрика |
| гараж кв.19 | канистры, патроны, топор и тулуп — у Петра, охотника |
| Игорь, Костя, Лида | ничего. Они и пойдут срывать чужие замки |

Из устройства кладовой следует четыре вещи, которых в доме не было:

- **законное место на первую неделю.** Дни 1–3: 100 спусков в погреб против
  нуля вылазок в чужое;
- **асимметрия, которую видно.** «Пётр спускался в подвал и вернулся не
  с пустыми руками» — это сигнал наравне с дымом из окна, и из него растёт
  чужая оценка запасов, то есть зависть;
- **буран перестал быть общим.** В погреб спускаются и в минус сорок; в гараж
  уже нельзя, а на улицу тем более. У кого погреб — тот буран пережидает;
- **цель, которая не человек.** Сорвать замок в подвале легче, чем прийти
  к двери, за которой хозяин с ружьём: это ступенька между разобранной пустой
  квартирой и налётом, которой раньше не было.

Из погреба при этом **не выгребают всё разом**, и не от лени: наверху запас
можно украсть, а внизу за замком он лежит. Человек поднимает то, чего ему
не хватает на несколько дней вперёд, — и оттого выглядит бедным в квартире,
оставаясь богатым в подвале. Отсюда же берётся ответ на вопрос, почему он
не делится: **в его собственную арифметику подвал не входит.**

**Ключом не делятся.** Не запрет, а устройство: ключ — не вещь, которую можно
отдать штукой, а доступ ко всему сразу и навсегда, и в обычный обмен он
не входит вовсе. Ходит он только вместе с имуществом: гость и союзник получают
доступ, пока они гость и союзник; ключ мёртвого висит на гвозде в прихожей
и находится при разборе квартиры; ключ живого вытряхивают из кармана
на лестнице вместе с ключами от двери. Замер, 40 жизней: 73 перехода ключа
и **ни одной добровольной передачи.**

Чужое при этом стало чужим и на улице, и у места стало **две мерки вместо
одной**. «Дичь» ранжирует места между собой — пока за углом магазин, в мусорке
не роются. «Мерка» решает, годится ли такой выход вообще, и разрядов у неё три:

| место | мерка | НОРМА |
|---|---|---|
| магазин на Заречной | `вылазка` | 0.18 — обычная жизнь |
| двор и мусорки | `вылазка_двор` | 0.80 — не преступление, но поступок из другой жизни |
| соседние подъезды, гаражи за домом | `вылазка_чужое` | 0.95 — чужой замок, метка «воровство» |

Двор понадобился отдельным разрядом не сразу, а после первого же прогона:
когда чужое закрылось нормальностью, а у двора своих ворот не было, он стал
наименьшим злом и открылся с первого дня — хотя до захода открывался
к шестому. Одной дичью это не держится: она входит в оценку слагаемым
и сравнивает места, а не запрещает выход. 0.80 при этом нарочно ниже
`нормальность_дикость_порог` (0.9): помойка — это не «так теперь можно»,
это просто стыдно, и дом на это не смотрит.

Метка «воровство» у чужого работает только на самого человека: дом слышит
«вернулся с пакетами», а куда тот ходил, не видел никто.

| | было | стало |
|---|---|---|
| вылазки в чужое в первый день | 44% | 0% |
| вылазки по мусоркам в первый день | 0% | 0% |
| первая вылазка вне магазина и своей кладовой | день 1 | день 4 |
| первая вылазка в чужое | день 1 | день 5 |
| вылазки Оксаны в чужие подъезды за дни 1–3 | 2.6 за жизнь | 0.0 |

Гаражный ряд за домом — общий, и часть боксов в нём принадлежит этому же
подъезду. Рано или поздно сорванный там замок оказывается соседским,
и вылазка «в никуда» превращается в повод, у которого есть имя.

## Снег, угар и слух

Четыре вещи, и три из них про одно и то же: **между тем, что происходит, и тем,
что дом знает, до сих пор не было зазора.** Человек умирал — знали все, мгновенно,
включая того, кто спал за двумя стенами. Тихая смерть, во сне, была невозможна
не потому, что не бывает, а потому, что её некому было бы не заметить. Уйти было
нельзя, хотя дом трижды получает известия, что снаружи что-то есть.

### Снег как величина

Погода была температурой и режимом. Снега как количества не было вовсе — поэтому
улица на двадцатый день была ровно такой же проходимой, как на первый.

`House.снег` — метры во дворе. Прирост постоянный, убыль — доля от того, что уже
лежит: снег не тает, он слёживается под собственным весом. Поэтому высота сама
выходит на потолок, а не упирается в него: 0.81 м к третьему дню, 2.18
к пятнадцатому, 2.31 к тридцатому. Буран досыпает сверху, затишье осаживает.

Снег входит в три места и больше никуда: во время дороги (`погода_часы`),
в шанс сломать ногу и в шанс дойти до пункта обогрева.

Про время дороги стоит сказать отдельно, потому что мерка была выбрана неверно.
Проверялось так: «число вылазок во второй половине метели не должно упасть больше
чем на четверть». При `снег_дорога` 0.35 оно падало на 38% — и правка выглядела
провалившейся. Но часы, проведённые на улице в пересчёте на живого человека,
при этом **не менялись вовсе**: 2.33 без снега и 2.33 с ним. Ходок стало меньше
ровно потому, что каждая стала длиннее. Число ходок мерило не то; улица
не закрылась, она подорожала. По часам и настроено: 0.25, к третьей неделе та же
дорога стоит в полтора раза дороже, и дальние места закрываются сами собой —
не запретом, а тем, что до вечера не успеть.

### Травма — от дороги, а не от «риска места»

Замер показывал: **103 травмы на 337 походов в магазин за первые три дня**.
Каждый третий, кто пошёл за продуктами в первый день метели при минус девяти,
возвращался с переломом. Причина была в том, что у места стояло одно число `риск`
и делало три работы сразу: шанс травмы, шанс встречи с людьми и осторожность
при выборе. У магазина риск был 3.0 — самый высокий, — потому что он дальше всех.
Но «дальше» и «опаснее» это разные вещи.

Теперь у места две мерки:

| место | дорога (лёд, темнота, расстояние) | угроза (люди) |
|---|---|---|
| двор и мусорки | 0.35 | 0.4 |
| соседние подъезды | 0.50 | 1.0 |
| гаражи за домом | 0.90 | 1.5 |
| магазин на Заречной | 1.40 | 1.0 |

Травма считается от `дороги` и не плоско, а по состоянию улицы: снег, погасшие
фонари, мороз (`world.дорожные_условия`). Встреча с людьми — от `угрозы`,
осторожность при выборе — от суммы обеих, а оружие валяется там, где опасно,
а не там, где далеко.

Стало: поход в магазин на первой неделе — 8% травм вместо 29%, на второй-третьей
22%. Оно наконец растёт, а не стоит: 8% → 7% → 11% → 9% по всем местам.
Общее число травм при этом упало вдвое с небольшим, и это цена, о которой стоит
знать: улица осталась опасной, но перестала быть опасной с первого дня.

### Вентиляция и угар

Люди не идиоты: печку в наглухо закрытой комнате не жгут, потому что есть
вытяжка. Но вытяжка в панельном доме обрастает льдом изнутри — от собственного
пара, — и в какой-то день перестаёт тянуть. Об этом никто не думает, потому что
об этом никогда не приходилось думать.

`Flat.вентиляция` падает тем быстрее, чем холоднее снаружи, чем больше топят
и **чем плотнее заклеены окна**. Ловушка нарочная: утепление — единственная
защита от холода и единственная дорога к угару.

Предупреждение даётся всегда, прежде чем убить: голова, тошнота, свеча у окна,
которая ночью гасла сама. Ниже второго порога — смерть во сне, вместе со всеми,
кто спал в этой квартире. Дежурный на площадке уцелеет: он всю ночь просидел
за дверью — и утром войдёт первым.

Догадаться, что дело в шахте, можно тремя путями, и все три честные: по себе
(утром болела голова), по уму и с чужих слов. Второй путь — единственное место,
где `сообразительность` наконец начинает что-то значить: до этого черта решала
ровно один вопрос на весь код. Замер: смышлёные лезут в вытяжку **до** того, как
им стало плохо, 2.2 раза за жизнь против 0.6 у прочих.

Третий путь — социальный, и с ним вышла поправка к замыслу. Предполагалось, что
тот, кому было худо, скажет об этом в чате. Но вытяжка обмерзает к двенадцатому —
пятнадцатому дню, а связь умирает на десятый (GDD 19): чат к этому времени мёртв.
Поэтому знание ходит разговором в дверях — и это оказалось вернее.

Смертей от угара 0.17 за жизнь (4% всех смертей), предупреждение спасает 90%.

### Дом узнаёт о смерти не сразу

`NPC.знает_о_смерти` — чьи смерти этот человек знает. Паника, привычное
и происшествие достаются теперь свидетелям, а не всем шестерым разом. Свидетели
по умолчанию: убийца и те, кто спал за той же дверью. Драка, выстрел и выломанная
дверь слышны всему подъезду — там свидетели все.

Дальше известие ходит **слухом**, через тот же `gossip`, что и всё остальное,
и упирается в то же самое: кто рассказчику не верит, принимает не известие,
а вопрос — откуда ты знаешь? Механизм тот же, что у наговора, и разоблачается
он так же — не доказательством, а тем, что «покойник» выходит на площадку живым.
С той разницей, что здесь покойник не выйдет никогда. Подозрений в убийстве
из-за принесённого известия: 0.64 за жизнь.

Знанием гейтится ровно то, где человек действует по своему представлению.
Правда мира — `h.alive()` и `h.пустые()` — остаётся правдой для расхода еды,
температуры и геометрии осады. А вот **«эта квартира пустая»** стало вопросом
представления: `h.пустые_для(npc)`. Иначе выходила нелепость, ради которой всё
и затевалось: квартира становилась общим достоянием в тот же день, когда хозяин
перестал дышать, — раньше, чем об этом успевал узнать хоть кто-то.

### «Не отвечает третий день»

Без этого тихая смерть не читается вовсе: человек просто исчезает из журнала.

Мёртвый не шумит, не пахнет готовкой и не попадается на лестнице. Через три дня
молчания у соседа появляется мысль сходить и посмотреть — действие `проведать`,
час работы, метка «порядок», та же, что у выноса тела. Тормозят его ненависть
и страх; торопит запах по стояку, который через пять дней делает тихую смерть
нетихой сам собой.

Он вскрывает дверь и находит то, что находит — и тут же выходит на площадку
и говорит. Тело не бывает частным знанием: держать его при себе не станет никто.
Но говорит он всё равно словами, и весят они ровно столько, сколько ему верят, —
поэтому весть расходится не ко всем и стоит ему подозрений. Дом узнаёт о смерти
задним числом и **от него одного**, а значит, он же и первый, кого спросят,
откуда он знает. Забота оплачивается подозрением, и это ровно та цена, которая
в такой ситуации и бывает.

Без этого «выйти и сказать» выходила отдельная нелепость: четверо по очереди
вскрывали одну и ту же дверь и по очереди находили одно и то же тело.

Замер: 90% тихих смертей до 25-го дня дом обнаруживает, медианная задержка —
три дня. После 25-го — уже нет, и это не поломка: в доме, где к концу живут двое,
третий может так и остаться неоплаканным.

Постучаться в дверь покойника по-настоящему человек не может, и это стоит
записать честно. Пока он не знает, что сосед мёртв, соседа нет и в списке живых;
вернуть покойника в перебор людей значило бы, что у него просят еды. Поэтому
считается не «сколько раз не открыли», а сколько дней от человека нет ни звука —
для мёртвого это одно и то же.

### Уйти к пункту обогрева

Дом трижды получает сообщения, что снаружи есть куда идти: слух про гуманитарку
у школы, радио про коридор с областной трассы, объявление на двери подъезда.
Ответить на них было нечем. Тридцать дней при минус двадцати семи — и ни один
из шести ни разу не сказал «пошли отсюда». Это была не клетка по замыслу, а дыра.

Пункт обогрева — не место вылазки, а **расстояние**: четырнадцать часов ходу
против восьми до магазина, и снег делает их длиннее. Само объявление — вещь,
а не знание: его видели не все, и дальше оно расходится разговором.

Бросок один, по четырём вещам, и все четыре уже были в модели: снег, мороз,
одежда, здоровье, ребёнок. Исходов два:

1. **Вернулся с полпути** — вдвое чаще, и это самый нужный исход. Потерян день,
   минус тепло, шанс обморожения, но человек жив и теперь **знает**, что дороги
   нет. Знание расходится по дому. Это цена надежды, и она делает вторую попытку
   решением, а не повтором.
2. **Ушёл.** Уходит со всем, что может унести. Дошёл он или замёрз на объездной —
   **дом не узнаёт никогда**, и это правильно: изнутри подъезда оба исхода
   выглядят одинаково. Правда видна только с `--секреты`.

Третьего исхода нет. В итоговом отчёте появилась третья строка рядом с «выжили»
и «погибли», и она нарочно не сливается ни с одной из двух:

```
Ушли (2):
  день 13 — Лида     ушла к пункту обогрева, не вернулась   ⌁ замёрзла на объездной
  день 14 — Оксана   ушла с Ваней, не вернулась             ⌁ замёрзла на объездной
```

Толкают уход отчаяние, ребёнок (мать уходит не за себя: он повышает решимость
и снижает шанс дойти) и то, что терять нечего. Держит одно — вложенное в свои
стены, тем же числом `flat.вложено`, которым уже считается привязанность к своему
углу. И ещё одно: пока человек верит, что улица ещё кормит, он никуда не идёт —
то же сравнение, которым держится и кража. Без него уходили на четвёртый день
метели, при работающем магазине.

Уходов 0.32 за жизнь, возвратов вдвое больше, медиана дня ухода — 22-й. Главный
риск был в том, что дом опустеет: не опустел. Живых в подъезде по дням
6.00 → 5.74 (10-й) → 4.66 (15-й) → 1.34 (30-й) — та же кривая, что и раньше.

## Близость, взгляд, замысел и быт

Четыре захода про самих жильцов, а не про то, что с ними случается. Основание —
замер `живость.py`, который меряет не события дома, а то, как человек решает.

Первым делом он опроверг очевидное. Механизм выбора оказался здоров: у человека
медиана пять вариантов выше порога, в 45% ходов выбирается не лучший, в четверти
ходов отрыв первого от второго меньше десяти процентов. И при этом двое случайных
жильцов расходились всего на 10% времени. Гипотезу «шум смазывает характеры»
проверили прямо: `температура_выбора` 0.55 → 0.05, то есть почти жадный выбор, —
расхождение выросло с 10% до 16%. Шум ни при чём.

Настоящая причина нашлась в разложении доверия на «кто цель» и «кто именно
к кому»: **80% различий объяснялось репутацией и только 20% личным отношением.**
Таблица «кто к кому ходит» была шестью одинаковыми строками: все ходили к Лиде,
никто не ходил к Игорю, и Оксана со второго этажа ходила к Лиде на третьем вчетверо
чаще, чем к Игорю на первом.

### Близость: пятая шкала отношения

Доверие, ненависть, страх и осведомлённость — это то, что человек **думает**
о соседе, и потому все четыре сходятся у всех к одному: сосед ведёт себя со всеми
одинаково, и дом судит его одинаково. `NPC.близость` — то, что между этими двоими
на самом деле **было**: разговоры, донесённые банки, отданные долги, ночи под одной
крышей, сдержанное слово.

Три вещи делают её работающей, и без любой из них она бы не работала.

**Симметрия.** `social.сблизились` прибавляет обоим сразу: разговор — событие пары,
а не поступок одного.

**Ограниченность внимания.** Прибавка тем меньше, чем больше человек уже со всеми
свой. Вечер у одной двери — это вечер не у остальных. Без этого близость была
положительной обратной связью без тормоза: в первом заходе все стали разговаривать
со всеми, разговор занял 23% всего времени дома, и дом вышел **однороднее**, чем был
на одной репутации.

**Предпочтение вместо величины.** В выбор входит не сама близость, а разница
с средней (`NPC.предпочтение`): тот, кто одинаково близок со всеми пятерыми,
не предпочитает никого.

Начальная несимметрия берётся из `доверие_старт` в npcs.json: Оксана с Лидой (8 и 7)
входят в метель парой, Игорь с Петром (1 и 2) — никем друг другу.

Что из этого выросло на 60 жизнях: **Оксана считает Лиду ближайшей в 95% жизней,
Лида Оксану — в 77%, Пётр Виктора — в 52%.** Средняя близость 2.3 при разбросе 2.3 —
и важен здесь именно разброс.

Заодно близость заменила фальшивое условие союза. Раньше там стояло
`earned = ... or h.day >= 6`, то есть после шестого дня условие выполнялось у всех
и не значило ничего; теперь союз требует взаимной близости.

### Кто судит поступок: участник или зритель

`judge` получил `участники`, и зритель весит `суд_вес_зрителя` (0.4) против единицы
у участника. До этого при отъёме на лестнице жертва получала одно значение
ненависти, а каждый из четырёх зрителей — своё, и **дом суммарно злился вчетверо
сильнее, чем тот, у кого отняли.**

Отдельно починена помощь: `judge(h, npc, "щедрость", trust=0.35)` шёл всему дому
безусловно, хотя осведомлённость о той же передаче бросалась по `заметность_помощи`.
Теперь судят те, кто заметил. Это и был главный двигатель общей репутации.

Разложение после всех правок: **74% репутации против 26% личного** (было 80/20).
Цель плана — 60/40 — не достигнута, и причина видна: Лида действительно ведёт себя
щедрее всех, а Игорь действительно всех задирает, и каждый убеждается в этом лично.
Часть репутации в этом доме настоящая.

### Взгляд: что человек видит в соседе

Осведомлённость была про чужой шкаф — сколько у него банок. Про самого человека
не знал никто: код читал `t.sick` и `t.injuries` прямо из правды мира, и человек
нёс аптечку тому, кого не встречал неделю.

`NPC.вид` — каким сосед **кажется**: сыт ли, цел ли, не мёрзнет ли, и отдельно —
видна ли на нём рана или слышен ли кашель. Обновляется при всякой встрече лицом
к лицу (`social.встретились`) и односторонне при наблюдении. Точность падает
в темноте и растёт со знакомством; оценка ползёт к правде, а не подменяется ею,
поэтому позавчерашнее впечатление живёт, пока не посмотрят снова.

Медианная ошибка — **15 пунктов из ста**. Ноль был бы телепатией, полсотни — шумом.

Три разных ответа на одно и то же увиденное:

- **помочь.** Повод к помощи теперь — увиденная беда, а не правда мира. И отзывчивость
  падает с каждым днём метели (`помощь_самосохранение`): в первый день отдать банку
  осунувшемуся соседу почти ничего не стоит, на двадцать пятый это твой последний
  день еды. Замер: рано помощь идёт кому попало (13% — тому, кто плохо выглядит),
  поздно — почти только нуждающимся (89%);
- **добить.** `NPC.видимая_сила` — сила соседа такой, какой она кажется. Слабость
  видна и она приглашает; раненый, который держится прямо, этим и защищается.
  Входит в отъём на лестнице и в решение о налёте (`добить_за_слабость`);
- **ждать.** `NPC.не_жилец` — приговор на паре, а не на человеке: один сосед списал
  со счетов того, кого другой не списал. Ставится не с одного взгляда, а после
  `не_жилец_взглядов` подряд. Поднимает наблюдение за ним, снимает штраф с занятия
  его квартиры и отменяет помощь: банка уйдёт в мертвеца. Самый холодный расчёт
  в доме и самый обычный. Приговоров около шести за жизнь, и в 13% из них
  осуждённый выживает.

### Замысел: цель, которая живёт дольше дня

Раньше дольше одного дня жили ровно две вещи: обещание соседу и заказ мастеру.
Человек пересчитывал всё заново в каждом слоте, и дом читался как лента поступков,
а не как история. `house/замысел.py` — пять видов цели:

| замысел | что подкрашивает |
|---|---|
| `тепло` | утепление, буржуйка, дверь, топка, заказ печи |
| `запас` | вылазка, кладовая, обмен |
| `угол` | занять, разбор, переезд |
| `рассорить` | шепнуть, подбросить, наблюдение |
| `уйти` | уход, одежда, вылазка |

Замысел — не приказ, а перевес: слагаемое в `add()` рядом с пунктиками. Он **спит**,
пока человеку не до него (кончилась вода — идёт топить снег), и брошен, если нужда
держится дольше `замысел_терпит_дней`. Под замыслом проходит 61% человеко-дней,
из них 46% он спит; исполняется 3.0 замысла за жизнь, бросается 2.0.

Главное в нём — **честолюбие лежит в данных**, как и весь остальной характер.
Пунктики получили ключи `замысел_тепло`, `замысел_запас`, `замысел_рассорить`.
Без них замысел делал дом однороднее: «набить шкаф» брали все шестеро одинаково.
С ними на 40 жизнях выходит так:

```
              тепло    запас  рассорить
   Виктор       44%      47%        10%
   Игорь        16%       2%        82%
   Костя        17%      65%        17%
   Лида         98%       0%         1%
   Оксана       17%      78%         4%
   Пётр         98%       1%         0%
```

### Рассорить: два способа и цена за напор

Единственный замысел, у которого цель — люди, и потому единственный, который делает
дом непредсказуемым. Берут его не от злобы вообще, а от злобы на того, с кем самому
не справиться: в оценку входит `видимая_сила` врага против своей. Потому и приходится
чужими руками.

Как он ведётся, решает `сообразительность`:

- **`шепнуть`** — сказать выбранному слушателю про выбранного врага то, чего не было.
  Дёшево и разоблачается тем же, чем наговор: добрым поступком оболганного
  (`проверить_наговор`). Слушателя выбирает `замысел.кому_шептать`, и выбирает
  по-разному: умный берёт того, чей разрыв с врагом дороже всего стоит, — самого
  близкого к нему; глупый идёт к тому, кто под рукой, к своему. И сам наговор
  умный не любит: его можно проверить, поэтому `шепнуть_против_ума` уводит
  сообразительного к подбросу. Замер на 60 жизнях: у Виктора (ум 8) шёпот
  к подбросу 2.9:1, у Игоря (ум 4) — 5.6:1;
- **`подбросить`** — положить к двери врага то, что говорит само: кусок тела, если
  в доме уже дошло до этого, или чужую аптечку в доме, где вещи начали пропадать.
  Дом видит вещь и хозяина двери; кто положил, не видит никто, и это видно только
  с `--секреты`.

И то, и другое стоит **напора**. Каждый ход поднимает его, тихий день опускает;
чем выше напор, тем больше шанс, что дом сложит одно к одному — и тогда раскрытым
окажется не оболганный, а сам заговорщик, со всей ненавистью, которую он копил
на других. `замысел.осторожность` — предел, который человек себе позволяет, и он
обратен сообразительности: умный выжидает, глупый лезет каждый день.

### Быт с лицом и привычка к оружию

42% всего времени дома занимали «быт» и «отдых» — «занимался своими делами»,
«лежал и ничего не делал». Почти половина экранного времени ничего не говорила
о том, кто эти люди.

Теперь у быта есть условия **про человека**, а не про дом (`world.про_кого`):
умение, оружие в руках, ребёнок, пунктик, ценность, черта выше порога, живёт ли
один, мёрзнет ли, цел ли. Пётр разбирает и чистит ружьё, Виктор перебирает ящик
с инструментом, Оксана считает банки вслух, чтобы Ваня слышал спокойный голос,
Лида перематывает бинты, чтобы заняли меньше места. Новый быт — строка в данных.

Быт при этом остался бытом: он даёт полтора градуса тепла, потому что человек
двигался, — и только если есть силы (`быт_силы_порог`); голодному и не спавшему
тот же час даёт передышку, а не тепло.

И то, ради чего у быта появилась цена: **`NPC.рука`** — насколько человек свыкся
с этим оружием. Своё, с которым он вошёл в метель, привычно; охотнику привычно любое
огнестрельное — это его ремесло, а не эта конкретная винтовка. Чужое, снятое
с мёртвого, начинается почти с нуля и растёт от ношения, от ухода за ним в быту
и от того, что пришлось пустить в ход у двери. Входит в `power` множителем
(`ЧУЖОЕ_ОРУЖИЕ = 0.55`).

Замер: у Петра винтовка 1.00 всегда, у Виктора подобранная — **0.36**, то есть
почти на треть слабее в бою. Ружьё меняет хозяина, а умение — нет.

### Чего добиться не удалось

- **Разложение доверия 60/40.** Получилось 74/26 против 80/20 в начале. Часть
  репутации в этом доме настоящая: Лида правда щедрее, Игорь правда задира,
  и каждый убеждается в этом лично, а не с чужих слов.
- **Строки «кто к кому ходит» так и не разошлись** (14% при 13% в начале), хотя
  близость сложилась в устойчивые пары. Причина в том, что больше трети контактов —
  наблюдение, обмен и возврат долга, и они по устройству идут не к своему,
  а к тому, у кого что-то есть.
- **Расхождение между людьми — 11% времени** вместо задуманных 20–25%. Но если
  не считать фон, который у всех одинаков (быт, отдых, еда, питьё, топка), —
  **19% в среднем и 31% у самой непохожей пары**, и это уже в цели. Мерка была
  выбрана неудачно: половину дня занимает то, что характером не определяется.
- **Замыслы `угол` и `уйти` почти не берутся** (0.03 и 0 за жизнь). У «угла»
  разница между своей квартирой и лучшей пустой обычно не окупает привязанности
  к своим стенам; «уйти» проигрывает всему остальному, пока человек ещё жив.

## Счёты, засада и лестница

Замер после четырёх заходов показал вещь, которую никто не задумывал: **на другой
день после осады эти двое разговаривали и менялись банками как ни в чём не бывало.**
В три дня после ночи у двери 13% контактов между налётчиком и жертвой были
разговором, 16% — обменом, а отъём на лестнице — 4%. Налётчик заходил поговорить
к тому, чью дверь ломал, и приносил ему банку. Жертва в основном просто смотрела.

Причина в том, что осада оставляла после себя только чувства — ненависть и страх, —
а они входят в решения слабо и не везде: разговор вычитал ненависть, делённую
на двенадцать, а обмен не смотрел на отношения вообще, потому что сделка считалась
по товару.

### Обида: она не проходит от времени

`NPC.счёты` — вес неулаженного счёта к этому соседу, 0..100. Не мнение о человеке
(доверие), не чувство к нему (ненависть и страх) и не история пары (близость),
а то, что между ними **не улажено**.

Главное в ней — **обида не оседает от времени.** Ненависть оседает каждый день
сама собой, и потому через неделю после осады от неё оставались крохи; обида
не оседает вовсе. Её гасят только поступками, и только безвозмездными: донесённая
банка, перевязка, выход на площадку за человека, когда за его дверью стоят с ломом.
Ни разговор, ни сделка её не трогают — словами и меной это не улаживается.

И у виноватого своя мерка щедрости: **ему не нужен излишек.** Обычная помощь
идёт от того, у кого запаса больше, чем у соседа, — а к двенадцатому дню излишка
нет ни у кого, и мириться выходило нельзя ровно тогда, когда было о чём: 92%
случаев, где человеку было что заглаживать, кончались на «нечем поделиться».
Тот, кто виноват, несёт из своего и оставляет себе на день. Это и делает
принесённую банку поступком, а не подачкой.

И у неё есть **дно**, ниже которого она не опускается никогда. Человек, к чьей
двери приходили с ломом, может снова с тобой разговаривать и снова меняться — и всё
равно будет держать тебя на расстоянии до конца метели. Каждый разговор, каждая
сделка и каждая мысль поделиться с ним идут через вычет, который не исчезает.

Обида несимметрична нарочно: её держит тот, **кого** обидели. Обидчик получает свою
долю — он знает, что нажил врага, и знает, что тот ждёт случая, — но вшестеро
меньшую: для него ничего не отняли.

| что случилось | обида | прощается |
|---|---|---|
| постояли у двери и разошлись | 45 | да, одной банкой — и то для вида |
| откупился: отдал и они ушли | 60 | двумя |
| зажали на лестнице, засада | 50–55 | одной-двумя |
| **квартиру вынесли** | **100** | **никогда** |
| **выставили из своих стен** | **100** | **никогда** |

### Не прощу: то, чего не гасят ничем

`NPC.не_прощу` — у него вынесли квартиру или его самого выставили на мороз
из собственных стен. Такое не гасится поступками вовсе, и человек говорит это
вслух, при всех, в тот же день. В финальном отчёте это отдельная строка рядом
с «выжили» и «погибли»: **не простили.**

Непрощённый идёт первым во всём, чем в этом доме можно ответить: в засаде
(порог злости для него не нужен), в дневной краже, в отъёме на лестнице, в ноже
ночью, в выборе цели для замысла «рассорить». Мстят любым способом — это
и означает, что способ не выбирают.

И своим он уже не станет: близость к тому, кого не простил, не растёт вовсе.

Замер на 60 жизнях: непрощаемых обид 2.2 за жизнь, улаженных 0.17. Через 8–20 дней
после осады, кончившейся миром, между этими двумя снова появляется обмен (1% контактов);
после осады, кончившейся разграблением, — не появляется ничего, зато 6% контактов
это по-прежнему засада. Пятнадцать дней спустя.

### Засада: и та, и другая сторона приходят к одной мысли

`подкараулить` — сесть на площадке и ждать конкретного человека. Три часа времени,
и они тратятся, дождался он или нет. Дом этого не видит: человек сидит на своей же
площадке, у него есть на это право; видно только с `--секреты` и только тому,
кто пойдёт и посмотрит.

Главное в ней — **симметрия**. К мысли дождаться другого на площадке приходят обе
стороны: и тот, кто ломал дверь и не вошёл, и тот, чью дверь ломали. Разница между
ними только в том, что один хочет забрать, а другой рассчитаться. Замер: за три дня
после осады налётчик садится ждать жертву 53 раза, жертва налётчика — 38, и грабит
жертва обидчика чаще, чем он её (23 против 9).

Садятся не от храбрости, а от расчёта: в оценку входит превосходство по **видимой**
силе (`NPC.видимая_сила`), а не по правде мира. Тот, кто держится прямо, этим
и защищается.

Сама засада отличается от обычного отъёма тремя вещами: врасплох (множитель к силе),
вдвое выше шанс вытряхнуть ключи от квартиры и погреба, и есть смертельная ветвь —
если счёты тяжелы, он вооружён и заметно сильнее. Смертельная ветвь не убивает,
а бросается: дальше решает бой, и на площадке он может кончиться в любую сторону.

### Лестница: одна дешёвая привычка против всего этого

`лестница` — приоткрыть дверь и постоять, слушая, прежде чем выйти. Треть часа.
Предлагается тому, у кого есть причина: с кем-то счёты или кого-то он боится.

Если на площадке кто-то есть, человек видит его и **сегодня никуда не идёт**. И это
уже победа того, кто сидит: чтобы отнять у человека день, необязательно его бить.
А тот, кто выглянул, теперь знает, кто его ждал, — и боится его по-настоящему.

На 40 жизнях: засад ставится 2.8, срабатывает 0.9, **замечается 1.05** — то есть
привычка посмотреть перед выходом отбивает больше засад, чем их доходит до дела.
Ровно так это и должно работать: дешёвая осторожность против дорогого умысла.

## Ребёнок, прощение и площадка

Шестой заход не добавлял в мир ни еды, ни тепла. Он чинил **входы в решение**:
места, где человек не доходил до поступка, который и раньше был ему доступен.

### Ребёнок входит в то, что чувствует мать

Состояние ребёнка (`NPC.дети` — своя сытость, своё тепло, своё здоровье)
читали четыре места из сорока: поесть, топить, лечить себя, лечить чужого.
Его не было ни в одном из трёх чувств — а значит, ни в просьбе, ни в переезде,
ни в вылазке, ни в уходе к пункту обогрева. Мать промёрзшего и больного ребёнка
не шла ни просить, ни переезжать: сама-то она цела.

`NPC.ребёнку_плохо()` считается по самому слабому ребёнку и по самой
провалившейся из трёх его шкал и входит в `невмоготу` наравне с собственным
холодом и болью. Дальше он попадает всюду сам: в панику, в сон замысла,
в просьбу, в переезд, в костёр и в топку.

Детская смертность от этого не упала, и это честный результат: в тот момент,
когда ребёнку плохо, у матери **ноль дней еды в 94% случаев**, нет лекарств
в 70% и плюс десять в комнате. Помочь ей нечем. Изменилось то, что дом это
видит: она паникует, просится к соседям и просит у них — а не переставляет
банки в шкафу.

### Виноватому не нужен излишек

См. «Обида: она не проходит от времени» выше. Коротко: у того, кто виноват
перед соседом, своя мерка щедрости — он несёт из своего, оставляя себе на день.
Попыток загладить обиду стало 3.4 за жизнь против 0.33; мирится 31% пар против 5%.

### Собрание можно созвать, и оно может договориться

Раньше 70% собраний срывались в крик, а после срыва дом становился хуже, чем
до него, — то есть созвать площадку было ошибкой, которую зовущий не мог
предвидеть. `meeting.жар_ссоры` — одна формула на оценку и на исполнение: сколько
между этими людьми открытой злости, какие у них характеры и насколько у всех
рассыпалось привычное. Зовущий считает её по всему дому, само собрание —
по пришедшим; смелый и общительный зовут и на взводе.

Злость в ней берётся **средняя по парам**, а не самая громкая: один заклятый
враг в доме есть всегда, и по нему собрание не судят. Сорванных собраний
0.42 за жизнь против 0.92, договорившихся — 1.08 против 0.48.

### Ненависть больше не упирается в потолок

Она была единственной из шести шкал отношения, у которой рост не затухал:
доверие, осведомлённость и страх последние проценты набирают тяжело, а злость
шла к сотне по прямой. К двадцатому дню у 59% жильцов максимальная злость стояла
на 90 из 100 — и выразить второе зло было нечем: осада и разграбление прибавляли
к девяноста девяти ровно ничего. Теперь затухает и она: 28% вместо 59%.

### Горе именное

Смерть соседа давала всем одинаковую встряску. Теперь она умножается на то,
кем он был этому человеку (история пары плюс доля доверия), и у того, кто
потерял своего, опускается сам **пол нормальности** — как у матери, потерявшей
ребёнка, только слабее. После своего человек не возвращается прежним, и в журнале
это отдельная строка: «Для Петра это был не просто сосед».

### Об аптечке теперь просят

`most_needed` возвращал только еду, воду и топливо: больной с жаром шёл просить
у соседа банку тушёнки. Теперь у аптечки одна мерка на обе стороны
(`нужна_аптечка` — жар, две раны или больной ребёнок), и она идёт первой,
если своей нет. Отказ в ней считается не горизонтом — по нему аптечка в дефиците
всегда, — а вопросом «нужна ли она сейчас самому».

### У быта появилась причина

`быт` был единственным действием в модели, оценка которого не смотрела ни на что,
и при этом самым крупным: 21% всех ходов дома. Теперь он уступает настоящей беде —
своей и детской, — но не исчезает совсем: занять чем-то руки человеку надо.
Стало 14%.

Следом вылезло другое: матери стало нечего делать, и она легла — отдых поднялся
с 15% до 18%. Поведение честное, врал журнал. У быта появились два варианта
для матери, которой нечем помочь (новый ключ отбора реплик `ребёнку_плохо`),
и своя строка конца дня: «Оксана почти весь день просидела рядом с Ваней»
вместо «пролежала и ничего не делала».

### Мелочи, которые оказались не мелочами

**Выйти за человека на площадку** — самое сильное событие пары в этой игре —
не попадало в историю пары вовсе: защитник получал доверие, но своим не становился.
Теперь `близость_за_защиту` идёт обоим, как разговор и общая печка.

**Дрова гостя.** Каждое утро гость сносит своё топливо к хозяйской печке.
При съезде часть возвращалась, при выселении — ничего: единственная сделка
в доме без цены для второй стороны. Теперь гость помнит, сколько снёс, и уносит
своё — не больше того, что принёс, и не больше половины оставшегося у хозяина.

**Отказ в мене** запоминался вполовину: «у него этого нет» человек помнил,
«он на это не меняется» — нет, и назавтра шёл к той же двери с тем же
предложением. 83% всех отказов были повтором того же самого. Теперь помнит и то,
и другое, и делает из отказа вывод: не берёт мою воду за свою банку — значит,
воды у него хватает.

### Чья поленница и что бывает с тем, кого пустили

**Дрова гостя.** Уходя, он уносит то, что сносил к этой печке, — но спросив.
Поленница лежит в хозяйской прихожей и стала общей в то же утро, когда он её
принёс, и держится за неё не один хозяин, а все, кто у печки остаётся греться.
`отпустят_со_своим` складывает своя-нужда, злость, совесть, близость, страх —
и силу уходящего против суммы сил всех, кто остаётся: с тем, кто один стоит
их всех, о поленнице не спорят. Уходящего по-хорошему не держат почти никогда;
выставленному на мороз отказывают примерно в трети случаев, и это уже не
«разошлись», а счёт, который не проходит от времени.

**Обобрать и уйти.** Третий исход ночи в общей квартире, между «съехать
по-хорошему» и ножом. Мотив переехать не греться, а посмотреть, стоял в модели
давно (`переезд_расчёт` прямо считает чужой шкаф против совести гостя), а выхода
из чужой квартиры с добычей было ровно два: попроситься обратно ни с чем или
убить хозяина — ночная кража прямо пропускает того, с кем спишь в одной комнате.
Оттого человек, которому нужны были чужие банки, шёл за них убивать: не потому,
что дошёл до этого, а потому, что иначе с ними было не уйти.

Теперь он может собрать хозяйский шкаф и уйти к себе в ту же ночь. Замка нет —
он внутри; и шкаф он видел своими глазами, поэтому здесь считается правда мира,
а не оценка. Но хозяин остаётся жив и наутро точно знает, кто у него ночевал:
дом узнаёт всё и сразу, обида кладётся непрощаемая, собирается приговор. Уходить
при этом есть смысл только туда, где не замёрзнешь, — унесённые дрова свою же
квартиру и протопят, если в ней есть чем топить.

И то, чего не хватало с другой стороны: **хозяин теперь думает, кого пускает.**
Он считал тепло, еду, тесноту и выгоду соседства — и ни разу не спрашивал себя,
что за человек будет спать у его шкафа. Судит он по тому, что может знать:
репутация, ловили ли гостя на чужом, врал ли он ему и насколько всё уже не так,
как было. Чужой жадности в лицо не видно — оттого предательство и остаётся
возможным. Вместе выходит примерно одно ограбление на шесть начал совместной
жизни; убийство соседа осталось на своём месте — за ним идут те, кому нужна
не еда, а квартира.

### Что нашлось чтением полного лога

Тридцать дней подряд, глазами, а не метрикой. Восемь правок поведения: печку
собирали в первый день метели при горячих батареях (у своей стройки осталась
безусловная база, которую из заказа у мастера убрали заходом раньше); из
магазина уходили ни с чем, имея деньги на воду, потому что список покупок
возвращал одну позицию; заговорщик шептал одно и то же одному и тому же изо
дня в день, хотя правило «наговор — это разговор, а не ежедневная сводка» уже
было записано для разговора; «не поверила про Игоря: откуда ты знаешь?»
повторялось каждый день до конца метели; у голода и жажды не было верхней
передачи — сытость три и сытость пятнадцать для решения были одно и то же;
гость обирал хозяина в первую же ночь; быт повторял одну и ту же строку дважды
за день; и строка о поступке печаталась после того, что этот поступок вызвал.

Последнее стоит записать как правило, потому что попадается в третий раз:
**главную строку хода надо печатать сразу.** Иначе в журнале «Оксана взяла то,
что Виктор принёс, и кивнула» стоит раньше, чем «Виктор сам занёс еду Оксане»,
и читатель видит следствие прежде причины. Для этого в `execute` есть
`сказать()`.

И то, чем чинился гость, обирающий хозяина в первую ночь, — не ручка,
а недостающее знание: у переезда теперь записывается, **с чем человек шёл**.
Кто просился греться, тот первые дни не встаёт — он только что получил ровно
то, за чем шёл; кто просился посмотреть на шкаф, встаёт когда угодно. В общий
котёл человека приводит решение дома, поэтому умысла там нет вовсе.

## Генератор: вещь, а не рецепт

Генератор заказывали чаще печки и раньше печки: 76% всех уговоров о нём
приходилось на первые два дня, 94% — при работающих розетках, которые гаснут
на десятый. Цена — 5.6 едой и дровами, и это за целый двигатель.

Четыре причины, и все четыре одного класса — константа, которая делает желание
из ничего:

1. **В оценке стояла двойка** «просто так»: `(2.0 + холод * 3.5)`. Печка
   считается от холода, а холода в первые дни ещё нет, — и генератор выигрывал
   у печки тем, что не зависел ни от чего. Теперь оценка складывается из того,
   что генератор на самом деле даст: обогреватель без электричества мёртв,
   снег на нём топят, когда топить больше не на чем, свет в окне — настроение.
   У Петра обогревателя нет, и генератор ему почти не нужен; у Игоря есть.
2. **Доверие к мастеру прибавлялось**, а не умножало: `+ trust * 0.3` — это
   +0.9 к любому заказу при пороге действия 1.1. Доверие само по себе
   перетаскивало через порог работу, которая сегодня не нужна.
3. **Доски мастера оплачивались плоской полторашкой** независимо от количества.
   Семь материалов на генератор — это три с половиной уровня утепления или три
   дня топки мебелью. Теперь по счёту, ставкой за доску.
4. **Объявленная цена не равнялась взятой** (5.6 против 6.2): доплату
   за материал прибавляли при сдаче. В доме, где нарушенное слово судится
   как предательство, это должно быть одним числом. Теперь одно.

И главное: **из семи досок двигатель не собирается.** Движок в этой игре один
на весь дом, лежит он в погребе у слесаря, и всё, что делает электрик, —
приводит его в чувство. То же правило, что у оружия: почти всё, что есть
в доме, было в доме с первого дня. Отсюда и повод — единственный движок лежит
за замком, ключ от которого есть у одного человека.

| | было | стало |
|---|---|---|
| медиана дня уговора | 2 | 10 |
| уговоров при живом свете | 94% | 0% |
| цена | 5.6 | 12–20 |
| генераторов за жизнь | 0.8 | 0.2 |

## На чём сейчас стоит баланс

100 прогонов, «±» — половина 95%-интервала:

| | было до снега | сейчас (150 прогонов) |
|---|---|---|
| выживает из шести | 1.35 ± 0.13 | **1.34 ± 0.14** |
| ушли к пункту обогрева | — | **0.26 ± 0.08** |
| голод | 37% | **41%** |
| холод | 31% | **30%** |
| насилие (драка, выстрел, нож, налёт, изгнание) | 25% | 20% |
| угар во сне | — | **4%** |
| жажда, истощение, раны, болезни | 7% | 5% |

Шестой заход (ребёнок, прощение, площадка, потолок злости) выживаемости
не сдвинул — 1.35 → 1.34 при полуинтервале 0.14, то есть не сдвинул вовсе.
Так и задумано: он не добавлял в мир ни еды, ни тепла, а менял только то,
доходит ли человек до решения, которое и раньше было ему доступно. Насилия
стало меньше на пять пунктов — это и есть цена того, что с соседями снова
можно помириться.

Держат норму две ручки мира — `агрессивность_дома` (2.4) и `вылазка_добыча_база`
(4.8), — и крутить их надо в конце, одним заходом: каждая правка людей сдвигает
выживаемость, а замер даёт ±0.19, так что балансировать после каждой правки
значит гонять шум.

В этом заходе щедрость района поднята с 2.9 до 4.8, и это самая большая правка
одной ручки за всю историю прототипа. Причина не в том, что дому стало голоднее
по замыслу, а в том, что **снег отнял ходки, не тронув добычу за ходку.** Дорога
стала длиннее в полтора раза, а день остался шестнадцатичасовым: человек успевает
меньше выходов, каждый из которых приносит столько же. Ручка возвращает не еду,
а потерянные часы: за долгий переход по грудь в снегу теперь и приносят больше.

Три правки этого захода двигают выживаемость в разные стороны, и потому они
и балансировались один раз, в конце:

| | куда двигает | замер |
|---|---|---|
| меньше травм (дорога вместо риска) | вверх | +0.02 |
| снег дороже по времени | вниз | −0.27 |
| угар во сне | вниз | −0.14 |
| уход к пункту обогрева | «выживших» меньше, погибших не больше | −0.04 при 0.32 ушедших |

Отдельно проверено то, чего боялись больше всего: что уход окажется выгоднее,
чем сидеть, и дом опустеет к середине метели. Не опустел. Живых в подъезде
по дням — 6.00 → 5.74 (10-й) → 4.66 (15-й) → 1.34 (30-й), та же кривая, что
и до ухода. Держит это снег и то, что унести можно немного.

Из прошлого захода (кладовые) стоит помнить вот что. Заметным там была
не выживаемость, а то, чем дом стал умирать. **Холод
и голод поменялись местами:** 36/26 стало 32/34. Кладовая отдаёт дрова сразу
и помногу (канистра — это канистра), а еду порциями, и дом стал реже замерзать
и чаще голодать. Насилие при этом просело с 30% до 25% — разница на грани шума
при шестистах смертях, но направление второй заход подряд не то, которого ждали.

Отдельно стоит записать, что кладовая сделала с помощью и с кражей. Передач
помощи стало 5.0 за жизнь вместо 7.5, а попыток кражи 9.6 вместо 14.2 —
и причина у обоих чисел одна: **человек с погребом держит наверху запас
на несколько дней, а не весь.** В квартире он выглядит бедным, поэтому и делится
меньше (излишка не видно), и красть у него ходят реже (брать нечего), и сам
он не идёт к чужой двери, пока внизу что-то есть. Налётов при этом стало
не меньше, а больше — 3.5 против 3.0.

Щедрость района остаётся самой крутой из двух. 150 прогонов на одних зёрнах:

| `вылазка_добыча_база` | выжило из 6 |
|---|---|
| 2.5 | 1.21 ± 0.12 |
| 2.7 | 1.18 ± 0.13 |
| 2.9 (было до снега) | 1.35 ± 0.13 |
| 3.1 | 1.36 ± 0.14 |
| 3.3 | 1.55 ± 0.12 |

После снега та же кривая сдвинулась вся целиком — 60 прогонов, мир со снегом,
угаром и уходом:

| `вылазка_добыча_база` | выжило из 6 |
|---|---|
| 2.9 | 0.78 ± 0.19 |
| 3.7 | 0.98 ± 0.18 |
| 4.3 | 1.22 ± 0.17 |
| **4.8** (сейчас) | 1.34 ± 0.18 (100 прогонов) |

Ниже 2.9 кривая ложится плашмя: между 2.5 и 2.7 разницы нет вовсе. Дом перестал
упираться в одну только бедность района — у него появилось, чем жить первую
неделю помимо улицы, и решает уже не то, сколько лежит в гаражах за домом,
а у кого есть ключ от подвала.

Вторая ручка, `агрессивность_дома`, проверена и оставлена как была. На 150
прогонах 2.4 даёт насилие 30% при выживаемости 1.24, а 2.8 — насилие 29% при
1.39: то есть она двигает выживаемость и не двигает насилие. Крутить её ради
трёх пунктов, которые не отличаются от шума, значит настраиваться на шум.

Жажда выросла с 1% до 5%, и это не про воду. Все десять умерших от жажды
за шестьдесят жизней были одновременно без дров и без воды: снег топят
на печке, и когда кончаются дрова, человек перестаёт и греться, и пить.
`_cause` выбирает самую провалившуюся шкалу, и у части людей ею оказывается
жажда, а не холод, — то же самое, только названо иначе.

Про насилие приходится записывать второй заход подряд. В прошлый раз шесть
новых поводов враждовать сдвинули его с 29% до 31%, и вывод был: **дело
не в поводах** — метель работает каждый день и на всех сразу, а вражда
по случаю и на двоих; нужно не больше причин для драки, а меньше способов
пережить холод в одиночку.

Кладовая была прямой проверкой этого вывода. Она делает холод **неравным**:
у Оксаны, Виктора и Петра есть куда спуститься в буран, у Игоря, Кости и Лиды
нет, и это работает каждый день, а не по случаю. Неравенство появилось —
первую неделю первые живут у своих запасов, вторые нет. Насилием оно не стало:
25% против 30%. Стало голодом.

Похоже, что дело и не в неравенстве тоже. Дом убивает метель, и всё, что
делает разницу между жильцами, делает разницу в том, кто умрёт от холода
и кто от голода, — а не в том, кто кого убьёт.

|---|---|

| `house/world.py` | метель, отключения, события трёх типов (GDD 21) |

| `house/engine.py` | цикл дня и ночи, расход потребностей, здоровье, смерть |

Разделение сделано так, чтобы это переносилось в Godot 4 по одному файлу за раз:
`model.py` → ресурсы Godot, `actions.py` → скрипт поведения NPC, `data/*.json`
остаётся как есть.

## Как устроено решение NPC

Каждый день у жильца 16 часов. Он перебирает все доступные действия, ставит каждому
оценку (примерно 0–10) и выбирает **мягко**: обычно лучшее, но чем выше паника, тем
чаще делает глупость. Потом тратит часы и начинает заново, пока часы не кончатся.

Ночью выбор другой и короче: спать, дежурить, пойти украсть — или, если сошлись
условия из раздела 16, собрать людей и пойти на осаду.

Три разных чувства управляют людьми, и путать их сорта нельзя.
**«мне не хватит»** считается по личному горизонту (сколько дней ещё терпеть —
никто не знает, и с каждым днём кажется, что дольше) и управляет отказами,
жадностью и паникой. **«я умираю»** считается по запасам и настоящему истощению
и управляет кражей и налётом. **«мне сейчас плохо»** — это холод в комнате, боль,
жар **и то, что плохо ребёнку на руках**; оно управляет топкой, костром,
просьбой, переездом и лечением. Когда
я свёл первые два в одно, сытые пошли грабить с первого дня. Когда третье
входило слагаемым во второе, у медианного ночного вора в первую неделю было
еды на десять дней: он лез к соседу потому, что у него болела нога.

Характер лежит в данных, а не в коде. Веса черт в решениях — таблица
`веса_черт` в `balance.json` (`лояльность × 4` в щедрости, `− лояльность × 4.5`
в краже). Правила поведения — **пунктики**: именованные сдвиги вроде
«первым не ударит», «сам разберётся», «злопамятный», которые раздаются людям
списком в `npcs.json`, как умения. В коде один интерпретатор на всё это.
Оттого Игорь за 40 прогонов ни разу ни с кем не поделился и 41 раз зажал соседа
на лестнице, а Лида 249 раз лечила и не отняла ничего ни у кого.

Ценности человека держат его руку двумя разными способами, и это тоже
не украшение. **Запрет вычитается** — «не терплю воровство» обязано уметь
остановить, даже когда очень хочется. **Склонность умножает** — «ценю работу»
делает человека охотнее в том, что он и так собрался делать, но не выдумывает
ему дела на пустом месте. Пока обе входили слагаемыми, склонность работала как
нужда: Виктор с его «руки решают» получал полторы банки прибавки к любой
постройке при нулевом холоде и собирал генератор на третий день метели, при
горячих батареях и работающих розетках.

Ключевое: **никто не знает правды о чужих запасах.** У каждого своя оценка того,
что у соседа есть, и она растёт от шума (запах готовки, дым из окна, гул генератора,
стук молотка), от прямого наблюдения и от чужих рассказов. Грабить идут не туда,
где богато, а туда, где **кажется**, что богато. Отсюда же и ложные обвинения:
обокраденный выбирает виноватого по репутации и по тому, что слышал ночью,
и часто ошибается.

## Чего здесь намеренно нет

Игрока, петли времени, рассудка, мини-игр, инвентаря вне времени, навыков,
телефона, вылазок в отдельные локации, 3D. Это прототип **одной** системы —
дома как социума. Игрок в него добавляется как седьмой жилец с теми же правилами
(GDD 13: «правило одно для всех»), но его решения принимает человек, а не оценка полезности.

Из того, что в GDD есть, а здесь нет по существу, а не по решению:

- **Расписание NPC (GDD 12.1: «где бывает в какое время дня»).** Внутри дня
  в прототипе нет часов — есть только счётчик оставшегося времени, — поэтому
  расписание выразить нечем. Ближайшее, что удалось: пока сосед на вылазке,
  его квартира стоит пустой и в неё можно залезть. Полноценное «планировать
  по расписанию» появится только вместе с внутридневным временем.
- **Отдельные локации вылазки (GDD 20).** Локаций как мест нет, но есть то,
  ради чего они в документе: выбор «ближе и беднее или дальше и опаснее».
  Двор, соседние подъезды, гаражи и магазин на Заречной различаются часами,
  богатством, длиной дороги и тем, кого на ней встретишь; смелость и нужда
  гонят дальше, мороз, снег и раны — ближе. Пятое направление — пункт обогрева
  в школе №7 — не место, а расстояние: оттуда не возвращаются с пакетами,
  оттуда не возвращаются вовсе. Записок, знаний и бункера нет.
- **Камера на пролёт и ловушки** (GDD 15, уровни 3 и 4). Камера без игрока
  почти ничего не даёт — смотреть в неё некому, — а ловушка это новый вид
  смерти, который надо балансировать отдельно. Остальные постройки этих
  уровней есть, и теперь их можно заказать у того, кто умеет.
- **Гипотеза, ради которой прототип задумывался.** GDD 25 говорит: «проверить
  одну гипотезу — интересно ли играть вторую жизнь, зная первую». Здесь
  проверяется другая: рождает ли дом социальные события сам. Подмена сознательная
  (вторая жизнь бессмысленна, пока дом неживой), но это стоит внести в документ
  как выполненный этап, иначе GDD и работа расходятся молча.

## Как это проверяется

Ошибка в симуляции почти никогда не выглядит как исключение. Она выглядит как
ветка, которая молча не выполняется, или как еда, которая молча исчезла.
Поэтому `check.py` смотрит на пять вещей:

| Что | Зачем |
|---|---|
| **Данные** | опечатка в id тихо стирает стартовые отношения, дубль id стирает жильца, несуществующий эффект события не делает ничего, а реплика с условием-опечаткой молча исчезает из чата |
| **Инварианты** | шкалы в границах, запасы не в минусе, мёртвый не в союзе, гость и хозяин знают друг о друге, квартира не числится пустой дважды, вентиляция в границах 0..1, ушедший не числится мёртвым, а знание о смерти — только о том, кто и правда умер |
| **Баланс ресурсов** | было + пришло == осталось + израсходовано + потеряно + унесено. Всё, что не сходится, — забытый счётчик или утечка. «Унесено» появилось вместе с уходом: банка, которую ушедший взял с собой, уходит из мира так же, как съеденная, и без этого первый же уход разваливает учёт |
| **Покрытие** | сколько раз каждое действие предлагалось и выполнялось; ветка с нулём предложений — мёртвый код. Реплики считаются там же: у реплики бывает условие, и оно может не выполниться ни разу за всю жизнь дома |
| **Детерминизм** | одно зерно даёт один прогон, в том числе в другом процессе с другим `PYTHONHASHSEED` |
| **Эталон** | отпечаток четырёх прогонов лежит в `data/эталон.json`; любая незаметная правка поведения тут же видна |

Проверкой реплик, например, нашлось, что девять фраз из двадцати шести не звучали
никогда: чат живёт до десятого дня (GDD 19), а паника доходит до порога и настроение
падает уже без связи. Две темы из пяти были мёртвым текстом.

Этой обвязкой найдено то, что глазами не находилось: гость изгнанного навсегда
оставался «живущим» у выброшенного на мороз и потому не мог топить собственную
печь; дневная кража была недостижимым кодом; из шести исходов осады случались три;
изгнанный днём и убитый ночью продолжали ходить, потому что списки на день и на
ночь составлялись заранее; еда исчезала из мира без всякого учёта.

Кладовые вошли в тот же учёт с первого дня, и это оказалось важнее, чем выглядит:
подвал — третье место, где лежат банки, и не считай его `world_total`, первая же
поднятая наверх банка выглядела бы приходом из ниоткуда. Учтённый, он сходится сам
собой и без единого счётчика — снимок мира делается до первого дня и уже включает
подвал, а подъём наверх остаётся честным перекладыванием. Так же считается движок:
он один на дом, ходит из рук в руки и расходуется, когда из него собирают
генератор, — то есть может и исчезнуть, и завестись сам.

Ещё одна проверка живёт отдельно и стоит того, чтобы про неё помнить. GDD 21
требует: «Распределение случайных событий фиксируется зерном жизни, чтобы игрок
не чувствовал несправедливости при повторе». Пока мир и жильцы тянули числа
из одного потока, это не выполнялось: достаточно было дать Петру лишнюю банку
еды — и весь календарь погоды съезжал. Теперь календарь строится один раз до
первого дня, своим потоком; проверено на 15 зёрнах, совпадение полное.
